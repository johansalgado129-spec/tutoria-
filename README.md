# Taller de recuperación de Matemáticas 10

Presentación web de seis temas: intervalos, pendiente, funciones cuadráticas, ley de senos, razones trigonométricas y teorema de Pitágoras.

## Abrir

Abre `index.html` directamente en un navegador. No requiere instalaciones, compilación, servidor ni conexión a internet.

## Controles

- Flechas izquierda/derecha: diapositiva anterior y siguiente.
- Barra espaciadora: mostrar el siguiente paso en una explicación.
- Tecla `F`: pantalla completa.
- Tecla `G`: índice general.
- Tecla `Esc`: cerrar el índice.
- Botones inferiores: navegación táctil y con ratón.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube los archivos `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. En **Settings > Pages**, selecciona **Deploy from a branch**, `main` y `/ (root)`.
4. Guarda y espera a que GitHub muestre el enlace de tu sitio.

Las imágenes de apoyo están incluidas localmente para que la presentación funcione sin depender de servicios externos.
